# Project skills

Skills in this directory are discovered automatically at session start.

## Naming convention

| Prefix | Meaning |
|---|---|
| `pstack-*` | Ported from upstream [pstack](https://github.com/cursor/plugins/tree/main/pstack) (MIT, Lauren Tan). Each carries a **Provenance** section naming the upstream version and every change made during the port. Upstream is a Cursor plugin, so none of these run unmodified. |
| `verify-*` | This repo's own verification skills, generated by `pstack-create-verification-skill`. Not ported; owned here. |
| anything else | Written for this repo. |

The `pstack-` prefix exists so an upstream diff is tractable: to re-sync, compare against the named upstream version and re-apply the listed changes.

## Installed

- **`pstack-create-verification-skill`** — generates a project-local `verify-<app>` skill (Launch / Doctor / Drive / Evidence / Cleanup) plus a feature map, then proves the generated skill by executing it once.

## Not ported (deliberately)

`maintain-verification-skill` is the upkeep companion to the skill above and is worth porting next. Everything else upstream is either Cursor-proprietary (`make-bot-ui`, the `benny` automation pack), dependent on Cursor's transcript format (`recall`, `automate-me`, `reflect`), coupled to Graphite and cloud agent fan-out (`orchestrate`, `autopilot-*`, the `orch` CLI), or wrong-stack for a Python project (`typescript-best-practices`).
